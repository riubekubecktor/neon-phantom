# ROBOT BATTLE: NEON PHANTOM

エイムも反射神経もいらない。予約して、同時に動く。読み合いで殴り合うネオン・ロボット対戦。

▶ **遊ぶ:** https://riubekubecktor.github.io/neon-phantom/

- ブラウザだけで動く（インストール不要・アカウント不要）
- CPU対戦：EASY / NORMAL / HARD
- オンライン対戦：「ONLINE ⇄」でルームを作って、招待リンクかルームコードを友達に送るだけ（P2P）
- 7×7の盤面、1ターン20秒、全員8BIT。フレーム4種・武器14種・スキル15種・ULTIMATE 8種
